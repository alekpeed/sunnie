# Sunnie Days OS Revamp — World Surfaces and Ambient Intelligence

This implementation turns the shared world snapshot into user-facing product surfaces instead of leaving it as background state.

The Collections destination now exposes Sunnie's World directly: Curio Cabinet objects, Memory Book chapters, contextual Language Moments, conservative repeated-destination recall, progression-driven presentation packs, and harmless contextual surprises. Photo Intelligence uses the system photo picker and Apple's on-device Vision classifier to suggest which existing Sunnie Days area a selected image belongs to; classification is advisory and does not mutate records.

Sunnie Home consumes the same snapshot and shows the active environment plus contextual language/surprise details. Archived trips remain eligible for Memory Book composition, so archiving a trip does not erase its chapter.

All of these surfaces remain derived from existing authoritative repositories. No second travel, memory, plant, reward, or photo database is introduced.
