# Reference Image Rules

## Canonical

The three images in `Canonical/` define Sunnie’s age, face, proportions, palette, softness, and overall visual identity.

## Context only

The two images in `Context/` define useful environments and costume concepts. They depict Sunnie as too mature and tall. Do not use their character proportions.

## Generated text

Text visible inside any generated concept image is not a product requirement. Use the written specifications for labels, navigation, copy, and feature behavior.

## Production use

These files are references. Do not assume they are optimized, layered, transparent, licensed for broad distribution, or suitable as final app assets. Create approved production assets before release.
